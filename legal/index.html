Privacy

Last updated November 9, 2026

navarreval.com is a personal website. It has no accounts, no forms, no advertising, no analytics trackers, and no cookies used for tracking.

Hosting

The site is hosted by Cloudflare. Like any web host, Cloudflare processes standard request logs (such as IP address, user agent, and the page requested) for security and performance, and may run a bot-check or security script to protect the site. See Cloudflare’s privacy policy.

Email

Email sent to an address at this domain is forwarded by Cloudflare Email Routing to a personal inbox. It is used only to reply to you.

Embedded videos

Some blog posts embed YouTube videos using YouTube’s privacy-enhanced mode (youtube-nocookie.com). When you play one of these videos, YouTube’s own privacy policy applies.

Separately, video thumbnails on some pages (such as the Recent Videos section of the Personal page) load from YouTube’s image servers (i.ytimg.com) as soon as the page opens, which shares your IP address and browser details with Google.

Book covers

Book covers on the Reading page load from Open Library (openlibrary.org). When those covers load, your IP address is sent to Open Library.

This site is not directed at children under 13, and it does not collect personal information from anyone.
